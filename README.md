# Roommate Finder

Roommate Finder is a frontend web application designed to simplify the process of exploring shared accommodation options. The platform provides a clean and user-friendly interface where users can browse room options and initiate the booking process.

The idea behind the project was to address the common challenge faced by students and working professionals in finding suitable accommodations and potential roommates through a simple digital solution.

## Features

- Browse different accommodation options
- View room categories and details
- Simple booking form with date validation
- Clean and responsive user interface
- Easy navigation across sections

## Tech Stack

- HTML5
- CSS3
- JavaScript

1. Clone the repository:

3. Launch `index.html` in your browser.

Alternatively, you can use the VS Code Live Server extension.

## Project Motivation

Finding affordable accommodation through traditional methods can be time-consuming and inconvenient. This project was developed as an academic initiative to explore how web technologies can be used to improve the user experience of discovering shared living options.

## Current Scope

This version focuses on the frontend experience and basic booking interaction. It serves as a prototype demonstrating the concept and user flow of a roommate and accommodation discovery platform.
